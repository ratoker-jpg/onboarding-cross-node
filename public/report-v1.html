Ключевой вывод

Готовность данных

Готовность данных по блокам карточки новичка.

Оценка по этапам

Итоговые оценки. Для обычных оценок: выше — лучше. Для риска: выше — хуже.

Звонки

Метрики звонков, загруженные звонки по этапам и результаты анализа по автомануалу.

Собеседование

Оценки по собеседованию из итоговых оценок и ручных заметок.

Учебные агенты

Диалоги с ботом учебки. Это не реальные звонки — они не оцениваются по рубрике звонков. Импортированные результаты показываются, если они есть.

Операционка

Дисциплина, статусы, просрочки, комментарии и операционные показатели.
